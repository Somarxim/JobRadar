# 目标企业与爬虫源清单

| 版本 | 日期 | 状态 |
|---|---|---|
| v0.1 | 2026-09-04 | 初稿 |

本文档维护 JobRadar 采集层的目标企业清单（对应 `crawl_sources` 表初始化数据）与去重别名映射。**所有 URL 在 W3 配置爬虫时逐一实地验证**（官网招聘栏目常有改版/换域名），此处只锁定目标范围与渠道类型。

## 1. 目标岗位方向（匹配词表基准）

| 方向 | 关键词变体（JD 中常见写法） |
|---|---|
| Agent/AI 研发 | Agent 研发工程师、大模型应用工程师、AI 应用工程师、AIGC 工程师、智能体开发 |
| AI 全栈 | AI 全栈开发、大模型全栈、AI 产品工程师 |
| 信息系统开发维护 | 信息系统开发与维护、信息化建设、软件开发与维护（军工所高频岗位名） |
| 传统后端 | 软件开发工程师、后端开发（Java/Python）、软件研发工程师 |
| （军工所兼收） | 嵌入式软件、软件测试、C++ 开发 |

城市偏好：默认跟随简历 target_cities；军工所集中在西安/成都/北京/上海/洛阳/贵阳等，检索时不设强城市过滤（避免漏掉可接受城市），由匹配 Agent 在综合契合维度评分。

## 7. W3 爬虫实施顺序

1. **国聘网**（一个源覆盖 §2–4 大部分单位，ROI 最高）
2. **牛客校招**（互联网 + 日程）
3. 航空工业统一招聘平台、航天科技/科工集团招聘页（按个人目标优先级）
4. 运营商与银行官网（多为静态页，Jsoup 足够）
5. 各研究所官网/公众号（反爬弱但结构各异，按工期逐个适配；抓不到走手动粘贴兜底）
